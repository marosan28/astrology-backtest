# astrology-backtest

This repository contains a historical research experiment comparing:
- Tropical Western mundane astrology (Model A)
- Sidereal Western mundane astrology, Fagan–Bradley ayanamsa (Model B)
- Traditional Jyotish mundane astrology, Lahiri ayanamsa (Model C)
- Non-astrological historical forecasting (Model D)
- Randomised control periods

This project does not start from the assumption that astrology is true. It applies a preregistered protocol to test whether any astrological model demonstrates repeatable correspondence with documented historical developments beyond what a non-astrological baseline would predict.
